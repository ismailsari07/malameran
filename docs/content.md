# Content

Site copy is supplied by the client. Development proceeds with placeholders so
copy is never a blocker.

## Placeholder policy

- Use realistic placeholder copy in English, not lorem ipsum — realistic length
  reveals layout problems that lorem ipsum hides
- Every placeholder string lives in one place per page so swapping is mechanical
- Mark placeholders with a `TODO(copy):` comment
- No placeholder ships to production without being flagged to the client

## Copy deadline

Agreed deadline: _to be confirmed in writing with the client_

If copy arrives after the stage is otherwise complete, swapping it in is a small
task. If it arrives after launch, it is still a small task. This is why placeholders
are used — it must never hold up delivery.
